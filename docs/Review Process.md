# Syllabus Development Guidelines

This file tells Claude how to draft, review, and revise course syllabi for this project. Follow these rules whenever generating or editing syllabus content. When a rule conflicts with a user request, point out the conflict and ask before proceeding.

---

## 1. Role and Scope

- Help authors create syllabi that comply with institutional standards (e.g., CHED issuances such as CMO No. 75 s. 2017: https://ched.gov.ph/issuances/).
- Every syllabus must align Course Outcomes (COs), Specific Learning Outcomes (SLOs), assessments, teaching strategies, ICT tools, and readings.
- Write clear, concise, professional, and supportive language. Avoid jargon. Use the same terminology throughout.
- Never invent citations or URLs. If a reading is needed and the author has not provided one, insert a placeholder like `[Author to supply reading]`.

---

## 2. Bloom's Taxonomy Reference

Use these numeric values when checking cognitive level.

| Value | Level | Order | Key Verbs |
|---|---|---|---|
| 1 | Remembering | LOTS | define, list, name, recall, recognize, repeat |
| 2 | Understanding | LOTS | classify, describe, discuss, explain, identify, summarize |
| 3 | Applying | LOTS | apply, choose, demonstrate, implement, solve, use |
| 4 | Analyzing | HOTS | analyze, compare, contrast, differentiate, examine, organize |
| 5 | Evaluating | HOTS | appraise, argue, defend, judge, justify, support |
| 6 | Creating | HOTS | compose, construct, design, develop, formulate, generate, plan |

Additional verbs that appear in the reference sample: critique (5), assess (5), integrate (6), execute (6).

- **LOTS** (levels 1–3): basic skills, acquiring and understanding information, often passive, assessed by recall or comprehension tests.
- **HOTS** (levels 4–6): analyze, evaluate, create; active learning, assessed by essays, projects, presentations.
- Both are needed: LOTS build the foundation, HOTS develop critical thinking and creativity.

---

## 3. Course Information (Step 1)

Every syllabus starts with these fields:

- Course Code (e.g., `EL 114`)
- Course Title
- Course Credit (e.g., 3 units)
- Nominal Duration (e.g., 54 hours)
- Prerequisite
- Course Description

### Course Description must include

1. **Policy standard guidelines**: explicitly reference the relevant policy (e.g., CMO No. 75 s. 2017).
2. **End goal of the course**: the knowledge, skills, and competencies students will have at completion.
3. **Teaching methods**: lectures, discussions, seminars, case studies, group work, etc.
4. **Context**: where the course fits historically, theoretically, or practically in the discipline.
5. **Output**: the deliverables students produce (assignments, essays, projects, presentations).

---

## 4. Course Outcomes (COs)

### Rules

- Each course has **3 to 5** COs.
- Start each CO with an observable action verb.
- Use **HOTS-leaning verbs**: Apply, Analyze, Evaluate, Create. **Do not use Remember or Understand verbs in COs.**
- Reserve **Creating** for the final CO where possible. (This is a guideline, not a requirement to end with Creating; the reference sample uses Creating verbs in more than one CO.)
- COs are student-centered: state what students will be able to do upon completion.
- COs must be specific, measurable, assessable, and aligned with program and institutional goals.
- Cover the essential content of the course, including both foundational knowledge and higher-order thinking.

### About apparent regression in CO levels

A final CO using "Demonstrate" (Applying, 3) after Creating COs is acceptable when the demonstration is a complex performance (integration, proficiency, adaptation) rather than simple application. When this occurs, note the justification in a comment or review note.

---

## 5. Specific Learning Outcomes (SLOs)

### Rules

- Each CO is supported by **3 to 5** SLOs.
- Each CO's SLO set must include these types:
  - **Introductory**: sets the stage with foundational concepts. Typically Remembering or Understanding.
  - **Mediating**: builds deeper understanding. Typically Applying or Analyzing.
  - **Finale**: culminates in mastery. Typically Evaluating or Creating.
- **Remembering** is used ONLY for Introductory SLOs. (It does not have to be the first SLO.)
- **Creating** is used ONLY for Finale SLOs. (It does not have to be the last SLO.)
- Within a CO, each SLO must be **at or above** the cognitive level of the previous one. Never go backward.
- Each SLO should generally be **at or below** the cognitive level of its parent CO.

### Allowed exception (SLO level above CO level)

A CO using "Demonstrate" (Applying) may have an Analyzing, Evaluating, or Creating SLO when that higher-level task is a necessary, integral step toward the demonstration. Examples from the reference sample:

- CO "Demonstrate content knowledge..." (3) with SLO "Compare and contrast..." (4).
- CO "Demonstrate pedagogical and technological knowledge..." (3) with SLOs "Integrate technology..." (6) and "Execute teaching by integrating technology..." (6), because these involve designing a new approach or producing a unique learning experience.

When using this exception, add a short justification.

---

## 6. Performance Assessment Outputs (Step 3)

Each CO maps to one or more tangible outputs. A valid assessment must satisfy all five:

1. **Direct alignment**: reflects the skill in the CO (e.g., CO "Design an instructional plan" gives output "Instructional Plan of a chosen topic").
2. **Measurability**: objectively evaluable against clear criteria.
3. **Demonstration of skills**: requires application, creation, or analysis, not just recall.
4. **Cognitive complexity**: matches or is slightly higher than the CO's level.
5. **Evidence of learning**: shows the student achieved the supporting SLOs.

**Reject** assessments that are simple recall tests for HOTS outcomes, vague or subjective tasks, or tasks unrelated to the CO.

## 7. Innovative Approaches and Strategies (Step 4)

Choose strategies that align with the SLOs and assessments. Use this catalog.

| Approach | Strategies |
|---|---|
| Constructivist | Problem-Based Learning, Collaborative Projects, Interactive Simulations |
| Behaviorist | Token Economics, Gamification, Drill |
| Cognitive | Socratic Questioning, Devil's Advocate, Metacognitive Strategies, Guided Discovery, Brainstorming, Interactive Lecture, Design Thinking |
| Social Learning | Modeling, Cooperative Learning Strategies, Peer Teaching / Peer Review / Pair Peer Review |
| Inquiry-Based | Guided Inquiry, Science Experiments, Field Studies, Case-Based Learning, Debate Teams / Walking Debate, Visual Displays, Gallery Walk/Run, Computer Tour, Project-Based Learning |
| Experiential Learning | Internship, Simulations, Virtual and Site Visits, Service Learning, Hands-On Activities, Virtual Labs (VLab) |
| Connectivist | Online Learning Communities / Collaborative Learning Spaces, Social Media Projects, Webinars and Online Conferences, Networked Learning Projects, Flipped Classroom |

Selection checklist: alignment with outcomes, student engagement, assessment results, variety and flexibility, feedback and reflection, resource availability, classroom context, overall effectiveness.

---

## 9. Required Readings / Materials (Step 6)

- List textbooks, readings, software, and other materials, and say where to obtain them.
- Each reading must support the CO, be current, accurate, and relevant, be at an appropriate difficulty, be manageable in quantity, come from varied sources, be accessible (consider cost), engage students, and feed into assessments.
- Verify that links work. Do not fabricate sources.

---

## 10. Syllabus Table Format

The main syllabus is a table organized by time frame (MIDTERM, FINAL TERM), with an examination row at the end of each term.

| Time Frame | Course Outcomes | Specific Learning Outcomes | Performance Assessment Outputs | Innovative Approaches and Strategies | ICT Tools / Resources | Required Readings | Teacher's Notes |
|---|---|---|---|---|---|---|---|

Each CO is followed by its SLOs. End each term with a `MIDTERM EXAMINATION` or `FINALTERM EXAMINATION` row.

### Reference example (Science teaching course)

**CO 1 (3, Applying)**: Demonstrate content knowledge of science in the K to 12 curriculum including its nature, content, domains of learning, and conceptual framework of the teaching of science.
- Explain the key characteristics and principles that define the nature, goal, scope of science and the domains of learning in the context of science education. (2)
- Summarize standards and the scope of science. (2)
- Compare and contrast the conceptual underpinning of the teaching of science in K to 12 Curriculum through Graphic organizer. (4)
- Output: Graphic Organizer
- Strategies: Brain-based learning, Interactive Discussion, Collaborative Learning, Multimedia Presentations

**CO 2 (6, Creating)**: Construct effective assessment tools in teaching science.
- Discuss the varied types and modes of assessment. (2)
- Critique sample test items and rubrics, identifying strengths and areas of improvement. (5)
- Develop traditional and authentic assessments tools that align with the objectives of science education in K to 12. (6)
- Output: Unit/Chapter Test, Tests and Rubrics
- Strategies: Think-Pair-Share, Critiquing Sessions, Interactive Discussion, Multimedia Presentations

**CO 3 (6, Creating)**: Design an instructional plan indicating learning outcomes, methods and strategies, assessment tools, instructional materials and teaching and learning activities.
- Discuss the different phases in lesson planning preparation. (2)
- Analyze the alignment of the learning outcomes, methods and strategies, assessment tools, instructional materials and teaching and learning activities utilized by a resource teacher during a class observation. (4)
- Design an engaging and inquiry-based science lessons that promote critical thinking, problem-solving, and scientific inquiry. (6)
- Output: Instructional Plan of a chosen topic in Science
- Strategies: Interactive Discussion, Critiquing, Collaborative Learning, Differentiated Instruction, Multimedia Presentations

**CO 4 (3, Applying)**: Demonstrate pedagogical and technological knowledge and skills in the teaching of science.
- Assess various educational technology tools suitable for science instruction. (5)
- Integrate technology in employing varied pedagogies in the teaching of science. (6)
- Execute teaching by integrating technology in employing varied pedagogies in the teaching of science. (6)
- Output: Teaching Demonstration
- Strategies: Critiquing Sessions, Group Discussions, Multimedia Presentations, Interactive Discussion, Differentiated Instruction

ICT tools used across all four COs: Google Classroom and other collaboration and productivity tools; Microsoft Office Suite and other educational software and tools; Projecting Digital Devices.

## 11. Writing Good Outcomes

**Bad (do not write):**
- "Understand the water cycle." (vague, unmeasurable verb)
- "Learn about cell structure." (vague)
- "Appreciate the importance of history." (subjective)
- "Know about plants." (too broad)
- "Be familiar with social media." (vague)

**Good:**
- "Describe the three main stages of the water cycle."
- "Label the parts of an animal cell diagram."
- "Explain two causes of the French Revolution."
- "List five characteristics of a desert plant."
- "Compare and contrast two social media platforms in terms of user demographics."

Principles: use Bloom action verbs, be specific, be measurable, be achievable within the term.

---

## 12. Syllabus Creation Workflow

1. Define course information.
2. Establish learning objectives (COs, then SLOs).
3. Determine assessment methods.
4. Set teaching approach and strategy.
5. List ICT tools/resources.
6. List required materials.
7. Review and revise.
8. Stay flexible and adaptable.

Build in this order so each later column aligns with the earlier ones.

### Optional policy content to include or ask about

- Grading scale (A, B, C, etc.)
- Late submission, make-up exam, and attendance policies
- Extra credit opportunities

---

## 13. Institutional Review Process

Syllabi pass through this review chain. Know it so you can label drafts and revision notes correctly.

1. **Author** drafts the syllabus.
2. **Program Review**: chairperson (or a senior if the chairperson is the author) reviews, then sends to the dean with suggestions.
3. **Dean Review**: dean reviews, then sends to CITL with suggestions.
4. **CITL Review**: CITL reviews, then returns the draft to the author with suggestions.
5. **Author Revision**: author revises per suggestions, then endorsement runs in order: Department Endorsement (chairperson with senior countersign), Dean Endorsement, CITL Endorsement.
6. **OVPAA** decides whether to endorse or return with suggestions. If returned, the syllabus goes back to the author through CITL.

## 14. Validation Checklist

Before finalizing any syllabus, verify each item and report failures to the user.

**Course info**
- [ ] Code, title, credit, duration, prerequisite present
- [ ] Description includes policy reference, end goal, teaching methods, context, and output

**Course Outcomes**
- [ ] 3 to 5 COs
- [ ] Each starts with an action verb at level 3 to 6 (no Remember/Understand)
- [ ] Creating verbs reserved for the final CO where possible
- [ ] Student-centered, measurable, aligned with program goals

**Specific Learning Outcomes**
- [ ] 3 to 5 SLOs per CO
- [ ] Introductory, mediating, and finale types all present
- [ ] Remembering used only in introductory SLOs
- [ ] Creating used only in finale SLOs
- [ ] Cognitive levels non-decreasing within each CO
- [ ] SLO level at or below the CO level, or a justified exception noted

**Alignment**
- [ ] Each CO has a compatible performance assessment output
- [ ] Strategies, ICT tools, and readings align with each CO
- [ ] Examination rows included for each term

**Quality**
- [ ] Consistent formatting, terminology, and tone
- [ ] Links and references verified or flagged
- [ ] Policies align with institutional guidelines

---

## 15. Output Behavior for Claude

- When asked to draft a syllabus, produce the table in Section 10 and run the checklist in Section 14 silently, then list any failed checks or judgment calls after the draft.
- When asked to review a syllabus, annotate each CO and SLO with its Bloom level number and flag violations of Sections 4 to 6.
- When revising, preserve the author's content unless a rule is violated, and explain each change briefly.
- Keep a short change log when revising, noting what changed and why.
- Ask for missing course information rather than guessing course codes, credits, durations, or prerequisites.
