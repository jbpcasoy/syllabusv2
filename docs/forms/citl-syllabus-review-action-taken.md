# CITL Syllabus Review Guide (Instructions for Part B)

This guide promotes consistency, coherence, and instructional quality in syllabus review. It helps reviewers ensure coherence between key syllabus components and alignment with institutional standards.

**Abbreviations used:**

| Abbrev. | Meaning |
|---------|---------|
| CO | Course Outcome |
| SLO | Specific Learning Outcome |
| PAO | Performance Assessment Output |
| IAS | Innovative Approaches and Strategies |
| ICT | ICT Tools and Resources |

## A. Format and House Style

Ensure the syllabus follows the prescribed conventions in Form 17 (Review Checklist).

| ID | Criterion |
|----|-----------|
| A.1 | Format: use the template prescribed by the university. |
| A.2 | Structure: present content in logical sections. |
| A.3 | Font style: Book Antiqua. |
| A.4 | Font size (see sub-items). |
| A.4.1 | Headings: 12 pt. |
| A.4.2 | Main text, page 1: 9 pt. |
| A.4.3 | Main text, succeeding pages: 11 pt. |
| A.5 | Line spacing: single throughout the document. |

## B. Alignment (Coherence and Logical Connection Between Learning Plan Components)

Check coherence and logical connection between components of the learning plan (CO, SLO, PAO, IAS, ICT).

| ID | Pair to check |
|----|---------------|
| B.1 | CO and SLO |
| B.2 | CO and PAO |
| B.3 | CO and IAS |
| B.4 | CO and ICT |
| B.5 | SLO and IAS |
| B.6 | SLO and ICT |

## C. Use of Behavioral Verbs (Bloom's Taxonomy)

Ensure outcomes are measurable and performance-based.

| ID | Criterion |
|----|-----------|
| C.1 | All Course Outcomes begin with behavioral verbs (e.g., demonstrate, analyze, evaluate, formulate). |
| C.2 | Specific Learning Outcomes are precise and observable. |

## D. Gradation of COs and SLOs

Verify that outcomes follow a clear hierarchical structure.

| ID | Criterion |
|----|-----------|
| D.1 | Hierarchical COs: arranged in increasing level of complexity. |
| D.2 | Overarching COs: COs that encapsulate the SLOs. |
| D.3 | Foundational SLOs (lowest complexity). |
| D.4 | Mediating SLOs (intermediate complexity). |
| D.5 | Terminal/Ultimate SLOs (highest complexity). |

D.3 to D.5 together require SLOs in increasing complexity: foundational, then mediating, then terminal/ultimate.

## Instructions for Claude (when using this file)

1. Use this file for **Part B (CITL Review)** of a syllabus review. For the Form 17 checklist criteria, use `obe-syllabus-review-checklist.md`. The two overlap on house style (A.1 to A.5 here vs. section I there) and on references and signatories.
2. Evaluate every ID (A.1 to F.3) in order. For each, produce one row for the Part B table: `Review Points (ID) | Action Taken | Page Number | Remarks`.
3. For each finding, cite the page number in the syllabus where the issue appears, and state a concrete suggested fix in Action Taken.
4. For section B, check each CO/SLO pair explicitly and name which outcomes or components do not connect.
5. For sections C and D, quote or list the offending outcome (the verb used, or the outcome that is out of order) rather than only saying it fails.
6. House style items (A.1 to A.5) need actual inspection of the file; if they cannot be verified, write "Unable to verify" in Remarks rather than guessing.
7. For F.1 to F.3, only confirm whether the forms are present in the submission. Do not complete the signature blocks, which belong to the human reviewers.
8. Part A is filled in by the program side, and the certification and signature lines are for humans. Do not complete them.
