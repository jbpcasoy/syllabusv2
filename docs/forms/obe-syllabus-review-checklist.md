**Institution:** Bukidnon State University, Malaybalay City, Bukidnon 8700

## Purpose

This checklist is used to review a course syllabus against the university's OBE (Outcomes-Based Education) standards for Hybrid Flexible Learning. For each criterion, the reviewer marks either **Yes** (meets standard) or **No** (does NOT meet standard) and may add remarks.

## Review Header (fields to fill in per review)

- Reviewer's Name:
- Date of Review:
- Course Code:
- Course Title:
- Name(s) of Course Instructor/s:

## How to Rate

For every criterion below, output one of:
- `Yes` = Meets standard
- `No` = Does NOT meet standard

Add a short remark for every `No`, citing the syllabus section/page and what is missing or wrong.

## Instructions for Claude (when using this file to review a syllabus)

1. Read the syllabus fully before rating anything.
2. Go through every criterion ID (A1 to I6) in order; do not skip any.
3. For each, output `ID | Yes/No | Remarks`. Every `No` must have a specific remark naming what is missing or wrong and where.
4. Criteria with sub-items (B6, C1, H3) pass only if all sub-items are satisfied.
5. House Style (section I) items need actual inspection of the file's formatting (page size, orientation, margins, font, sizes); if the format cannot be verified from the file, mark it as "Unable to verify" in Remarks rather than guessing.
6. End with a short, prioritized **Suggestions for Improvement** list and a summary count (total Yes / total No per section).
7. Do not fill in signatures or approval names; those are for the human reviewers.
